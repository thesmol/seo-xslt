# seo-xslt — задание №5

Практические работы по дисциплине «SEO — оптимизация портальных решений».

## Публикации и исходники

- №5: [GitHub Pages](https://thesmol.github.io/seo-xslt/task-05/), снимок этапа в `task-05/`.

Каждая папка этапа содержит свои ресурсы и не требует файлов последующих заданий.

## Локальный запуск

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Для AJAX и XML используйте HTTP, а не `file://`.

## Условия заданий

Ниже приведён полный текст соответствующих заданий из предоставленной постановки. Пути `addons/...` относятся к исходному учебному комплекту.

### Задание №5

```text
Написать XSL-преобразование для XML-файла m24_sitemap_categories.xml, которое выводит в браузере список основных разделов (url-адресов) сайта m24.ru с активными ссылками, дату последнего изменения и периодичность обновления.

    Написать XSL-преобразование для вывода в окно браузера информации из rss-ленты m24_yandex.xml:
        категория новости
        заголовок новости с активной ссылкой на страницу этой новости на сайте м24
        дату
        изображение
        полный текст новости
        сопутствующие материалы: изображение, заколокок материала, активная ссылка.

    Информация должна выводится в удобочитаемом виде, включая изображения, оформление вывода осуществить с помощью CSS.

В случае работы с локальными файлами в качестве xml-парсера использовать portable-версию браузера Firefox 62.

Приложение: addons/task5/...
```
