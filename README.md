# seo-xslt — задание №5

Здесь собраны работы по дисциплине «SEO — оптимизация портальных решений».

## Публикации и исходники

- №5: [GitHub Pages](https://thesmol.github.io/seo-xslt/task-05/), код в `task-05/`.

В каждой папке находится отдельное задание со всеми нужными файлами.

## Локальный запуск

```sh
npm ci
npm run dev
```

Откройте адрес, показанный Vite (обычно `http://127.0.0.1:5173/`). Для AJAX и XML используйте HTTP, а не `file://`.

Для сборки и проверки статической публикации:

```sh
npm run build
npm run preview
```

Для запуска нужен Node.js 20.19+ или 22.12+. При сборке файлы страницы копируются без изменений. Это сохраняет AMP-разметку и позволяет сравнивать исходные файлы в заданиях на производительность. Замеры лучше запускать через `preview`: в режиме `dev` Vite добавляет на страницу свой служебный скрипт.

## Условия заданий

Ниже — условия заданий. Файлы из `addons/...` находятся в исходном учебном комплекте.

### Задание №5

```text
Написать XSL-преобразование для XML-файла m24_sitemap_categories.xml, которое выводит в браузере список основных разделов (url-адресов) сайта m24.ru с активными ссылками, дату последнего изменения и периодичность обновления.

    Написать XSL-преобразование для вывода в окно браузера информации из rss-ленты m24_yandex.xml:
        категория новости
        заголовок новости с активной ссылкой на страницу этой новости на сайте м24
        дату
        изображение
        полный текст новости
        сопутствующие материалы: изображение, заколокок материала, активная ссылка.

    Информация должна выводится в удобочитаемом виде, включая изображения, оформление вывода осуществить с помощью CSS.

В случае работы с локальными файлами в качестве xml-парсера использовать portable-версию браузера Firefox 62.

Приложение: addons/task5/...
```
